# Пушистик (рабочее название)

AR-тамагочи для телефона: собери своего зверька, наведи камеру, и он появится у тебя в комнате.

- Концепция игры: [docs/game-design.md](docs/game-design.md)
- Стек: three.js + WebXR (AR через Chrome на Android), Vite. Звуки синтезируются в коде.

## Что уже есть (этап 0, прототип)

| Действие | Что происходит |
|---|---|
| Водить пальцем по голове или спинке | жмурится, мурчит, летят сердечки |
| Тык в носик | «а-а-апчхи!» |
| Тык в животик или воротник | хихикает от щекотки |
| Тык в ушко | дёргает ушком |
| Тык в хвост | обиженно «хмф!», хвост распушается |
| Тык в лапку | подпрыгивает |
| Тык в глазик или щёчку | «ой!» или смущается |
| Тык по полу (коврику) | зверёк бежит туда |
| 🎤 | Повторялка: скажи что-нибудь, и зверёк повторит тонким голоском |
| 🎨 | другой цвет шёрстки |
| 📷 | AR: зверёк появляется в комнате. С ARCore он стоит на настоящем полу, а без ARCore работает «режим камеры» (картинка с камеры + гироскоп) |

Сам по себе зверёк дышит, моргает, наклоняет голову, оглядывается, зевает, виляет хвостом и гуляет вприпрыжку.
В AR он бегает по полу и, если отойти от него подальше, бежит следом за телефоном.

## Запуск на компьютере

```bash
npm install
npm run dev
```

## На телефоне

Игра публикуется на GitHub Pages workflow-файлом `.github/workflows/deploy.yml` при каждом пуше в `main`.
AR и микрофон работают только по HTTPS, поэтому на телефоне игру открывают по ссылке GitHub Pages
(или через `chrome://inspect` с пробросом портов по USB).
